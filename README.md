# Drone Simulator

3D-симулятор квадрокоптера в браузере на Three.js.  
Полёты, посадка, крушения, сбор звёзд и полёты через кольца на 11 разных картах.

---

## Что нужно

- Браузер с поддержкой ES-модулей и WebGL (Chrome, Firefox, Edge, Safari — свежие версии)
- VS Code + расширение **Live Server** — самый простой способ запустить

Проект **не требует** Node.js, сборки, npm — это чистый HTML/JS.

---

## Запуск через Live Server (рекомендуется)

### 1. Установить VS Code

Скачать: https://code.visualstudio.com/

### 2. Установить расширение Live Server

1. Открой VS Code
2. Слева нажми иконку **Extensions** (`Ctrl+Shift+X`)
3. В поиске введи **Live Server**
4. Найди расширение от **Ritwick Dey** (у него больше всего установок)
5. Нажми **Install**

### 3. Открыть проект

1. В VS Code: **File → Open Folder…**
2. Выбери папку `drone-sim` (там, где лежит `index.html`)
3. Папка должна открыться целиком в левом дереве файлов

### 4. Запустить сервер

**Способ А — через правый клик:**

1. В левом дереве найди файл `index.html`
2. Правый клик по нему → **Open with Live Server**
3. Браузер откроется сам на `http://127.0.0.1:5500/index.html`

**Способ Б — через статус-бар:**

1. Внизу справа в статус-баре VS Code нажми кнопку **Go Live**
2. Откроется браузер с проектом

**Способ В — через палитру команд:**

1. `Ctrl+Shift+P` (или `Cmd+Shift+P` на macOS)
2. Введи `Live Server: Open with Live Server`
3. Enter

### 5. Играть

В браузере появится меню с выбором карт. Клик по карте — старт.

Чтобы остановить сервер: в статус-баре VS Code нажми **Port: 5500** (или правый клик → **Stop Live Server**).

## Управление

| Клавиша | Действие |
|---------|----------|
| `W` / `S` | Газ — вверх / вниз |
| `A` / `D` | Поворот корпуса (рыскание) |
| `↑` / `↓` | Нос вперёд / нос назад (тангаж) |
| `←` / `→` | Крен (влево / вправо) |
| `C` | Переключить камеру (следящая → FPV → сверху) |
| `R` | Респаун |
| `M` | Меню выбора карты |
| `Esc` | Закрыть меню |

**Правила:**

- Мягкая посадка — касание земли при вертикальной скорости < 4 м/с и наклоне < 30°. Зелёное сообщение «✅ Посадка».
- Крушение — скорость > 7 м/с, наклон > 48° или горизонтальная скорость > 6 м/с. Красное сообщение «💥 КРУШЕНИЕ».
- Столкновение с деревом или зданием — всегда крушение.
- **Таймер** стартует при сборе первой звезды (или пролёта первого кольца) и останавливается при сборе последней цели.

## Возможные проблемы

**Синий экран, ничего не реагирует**

Открой DevTools (`F12`) → вкладка **Console**. Скорее всего там ошибка. Пришли её текст — исправим.

**Открыл `index.html` двойным кликом — не работает**

Так и должно быть. Проект использует ES-модули и importmap, которые **не работают** через `file://`. Используй Live Server (или любой другой HTTP-сервер).

**Меню карт открывается, но при выборе карты всё падает**

Значит на этой карте ошибка в данных (например, звезда внутри здания). Проверь консоль — там будет видно файл и строку.

**Дрон появляется внутри здания или под землёй**

В карте неверно задан `spawn`. Физика сама ищет безопасную точку рядом, но если совсем плохо — правь `spawn: { x, y, z }` в файле карты.

## Как добавить свою карту

1. Создай файл `js/maps/my-map.js` по образцу существующих:

```js
const stars = [
  { x: 0, y: 20, z: 0 },
  { x: 40, y: 25, z: 30 },
];

export const myMap = {
  name: 'Моя карта',
  description: 'Описание',
  mode: 'stars',           // или 'rings'
  skyColor: 0x87ceeb,
  groundColor: 0x3f7a3f,
  groundBump: 1,
  sunColor: 0xffffff,
  sunIntensity: 1.2,
  hemiIntensity: 0.7,
  ambIntensity: 0.25,
  spawn: { x: 0, y: 15, z: 60 },
  trees: [],
  buildings: [],
  stars,
  rings: [],
};
