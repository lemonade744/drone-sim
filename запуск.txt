1. **Открой папку проекта в VS Code** — `File → Open Folder…` → выбери `drone-sim`
2. **Найди `index.html`** в левом дереве файлов
3. **Правый клик по `index.html` → Open with Live Server**
4. Браузер откроется сам на `http://127.0.0.1:5500` — играй

Остановить сервер: внизу справа в статус-баре VS Code нажми **Port: 5500** → Stop.

Если Live Server не установлен: `Ctrl+Shift+X` → в поиске **Live Server** → Install (автор Ritwick Dey).

**Управление:** `WASD` — газ и поворот, `↑↓←→` — наклон и крен, `C` — камера, `R` — респаун, `M` — меню карт.
